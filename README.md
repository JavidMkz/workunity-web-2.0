# WorkUnity — сайт для работодателей

Одностраничный сайт с отдельной страницей-инструкцией. Русский язык. Аудитория — работодатели девяти стран найма: Кыргызстана, Казахстана, Узбекистана, России, Азербайджана, Беларуси, Таджикистана, Грузии и Украины.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Главная: география, решения, процедура, отрасли, вопросы, форма |
| `kak-nanyat-inostrannogo-rabotnika.html` | Инструкция для работодателя, отдельная страница |
| `img/` | Иконка сайта и превью для соцсетей |
| `video/` | Сюда кладётся видеообращение, см. `video/README.md` |
| `en/`, `ur/` | **Собираются скриптом.** Английская и урду-версии всех страниц. Руками не править |
| `sitemap.xml` | Тоже собирается скриптом |

Фреймворков и зависимостей нет, страницы открываются двойным кликом. Но перед
публикацией нужно пересобрать языковые версии — см. ниже.

## Языковые версии

У каждого языка собственный адрес: `/`, `/en/`, `/ur/`. Это нужно поисковикам —
три языка на одном адресе индексируются как одна страница, и переводы просто не
попадают в выдачу.

**Источник правды — русские файлы в корне** вместе со словарями `I18N_EN`,
`I18N_UR` и `SEO` внутри них. Папки `en/` и `ur/` — результат сборки.

После любой правки текста:

```bash
npx http-server . -p 8731 &     # скрипту нужен локальный сервер
node scripts/build-langs.js     # пересобирает en/, ur/ и sitemap.xml
node scripts/verify-langs.js    # проверяет все 18 страниц
```

Сборщик запекает переводы прямо в HTML, проставляет `hreflang` и `canonical`,
превращает переключатель языка в обычные ссылки и генерирует разметку
Schema.org из содержимого страницы. Повторный запуск ничего не ломает.

## Публикация

Сайт развёрнут на **Vercel**, проект `workunity-web-2-0`, продакшен-ветка `main`.
Пуш в `main` выкатывает изменения автоматически, ничего запускать вручную не нужно.

Домен `workunityglobe.com` куплен в Squarespace, DNS обслуживается там же
(в Vercel в разделе Domains видно `Nameservers: Third Party`). Записи, которые
трогать нельзя: `A` на Vercel и TXT `google-site-verification=…` — на ней держится
подтверждение прав в Google Search Console.

**Перед пушем не забудьте пересобрать языковые версии** — см. раздел выше.
Папки `en/` и `ur/` лежат в репозитории и выкатываются как есть, поэтому если
забыть пересборку, русская версия обновится, а переводы останутся старыми.

Мета-тег `og:image` указывает на полный адрес `https://workunityglobe.com/img/og.jpg` — при смене домена обновите его, иначе превью ссылки в WhatsApp не подхватится.

## Особенности реализации

- Страница читается **без JavaScript**: скрипт добавляет класс `js` в `<html>`, и только после этого включаются появление по скроллу и залипающий блок процедуры. Всё содержимое, которое рисует скрипт, продублировано в разметке.
- Сроки оформления нигде не указаны намеренно, кроме согласованного диапазона 15–25 дней на подбор кандидатов.
- Разметка Schema.org собирается автоматически из содержимого страницы:
  Organization, WebSite, WebPage с хлебными крошками, FAQPage из блоков вопросов
  и HowTo из пронумерованных разделов инструкции.
- Шрифты подключаются с Google Fonts: Manrope, Inter, IBM Plex Mono.
