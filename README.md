# WorkUnity — сайт для работодателей

Одностраничный сайт с отдельной страницей-инструкцией. Русский язык. Аудитория — работодатели Кыргызстана, Казахстана, Узбекистана и России.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | Главная: география, конструктор заявки, решения, процедура, отрасли, вопросы, форма |
| `kak-nanyat-inostrannogo-rabotnika.html` | Инструкция для работодателя, отдельная страница |
| `img/` | Иконка сайта и превью для соцсетей |
| `video/` | Сюда кладётся видеообращение, см. `video/README.md` |

Сборка не нужна. Ни фреймворков, ни зависимостей — открывается двойным кликом, публикуется копированием на любой хостинг.

## Публикация через GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)` → Save.
Через минуту сайт открывается по адресу `https://javidmkz.github.io/workunity-/`.

При подключении своего домена замените относительные пути в мета-тегах `og:image` на полный адрес, иначе превью ссылки в WhatsApp может не подхватиться.

## Особенности реализации

- Страница читается **без JavaScript**: скрипт добавляет класс `js` в `<html>`, и только после этого включаются появление по скроллу и залипающий блок процедуры. Всё содержимое, которое рисует скрипт, продублировано в разметке.
- Сроки оформления нигде не указаны намеренно. Конструктор показывает порядок этапов и перечень документов, но не обещает недель и дней.
- Разметка Schema.org: Organization, Service с четырьмя странами, FAQPage.
- Шрифты подключаются с Google Fonts: Manrope, Inter, IBM Plex Mono.
